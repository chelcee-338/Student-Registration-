Student Registration System

A simple student registration website developed as part of my SIWES training.

Features

- Student registration form
- Form validation
- Success message after registration
- Stores student records in a MySQL database

Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL

Hosting

The website is hosted on InfinityFree.

Purpose

This project demonstrates my practical learning and application of frontend development, PHP backend programming, and database management during my SIWES training.
